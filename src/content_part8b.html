34. Viva Questions

Part 8  •  short spoken answers to the questions examiners actually ask

Viva answers should be short, start with the key term, and stop. Each answer below is written to be spoken in one or two sentences.

Keys

1. What is a key?

An attribute or set of attributes that helps identify a row in a relation and establish relationships between tables.

2. Difference between a super key and a candidate key?

A super key identifies uniquely but may contain redundant attributes; a candidate key is a minimal super key, so no attribute can be removed.

3. Can a foreign key be NULL?

Yes. A foreign key may take the NULL value, meaning no related row is currently assigned.

4. Can a foreign key be non-unique?

Yes — in fact a foreign key is usually not unique, because many rows in the referencing table normally point to the same master row.

5. What is the difference between a composite key and a compound key?

A composite key is a primary key of two or more attributes; a compound key is a composite key in which every part is itself a foreign key.

6. What is a prime attribute?

An attribute that appears in some candidate key; attributes in no candidate key are non-prime.

Dependencies and normalization

7. What does X → Y mean?

Any two tuples that agree on X must also agree on Y — X determines Y.

8. State Armstrong's three axioms.

Reflexivity: if Y ⊆ X then X → Y. Augmentation: if X → Y then XZ → YZ. Transitivity: if X → Y and Y → Z then X → Z.

9. Can you split the left-hand side of a dependency?

No. From AB → C you cannot infer A → C. Decomposition applies to the right-hand side only.

10. Why does normalization matter?

It removes redundancy and therefore the update, insertion and deletion anomalies that redundancy causes.

11. What is a partial dependency?

A non-prime attribute that depends on only part of a composite candidate key; 2NF removes it.

12. What is a transitive dependency?

A chain X → Y → Z where Y does not determine X; 3NF removes it.

13. Difference between 3NF and BCNF?

3NF permits X → A when A is a prime attribute even if X is not a super key; BCNF requires every determinant of a non-trivial dependency to be a super key.

14. What is a multivalued dependency?

When two independent multi-valued facts about the same determinant share one table, producing a cross product; 4NF removes it.

15. Why is 5NF largely of academic interest?

Because join dependencies are very difficult to detect in practice, as the source itself notes.

16. What is a lossless decomposition?

One whose relations, joined back, reproduce the original relation exactly, with no rows lost and no spurious rows created.

17. State the lossless-join test.

The common attributes of the two relations must form a super key of at least one of them.

18. Does denormalization mean abandoning normalization?

No. It is an optimization applied after normalization, adding redundancy deliberately to avoid costly joins.

Security

19. What is database security?

Protection from malicious attempts to steal or modify data — the array of controls, tools and procedures safeguarding confidentiality, integrity and accessibility.

20. Name the three properties security must preserve.

Confidentiality, integrity and availability.

21. Difference between authentication and authorization?

Authentication proves who the user is; authorization decides what that user may do. Authentication happens first.

22. Name the three access-control models.

Discretionary (owner-controlled, using ACLs), mandatory (labels and clearance levels), and role-based (permissions attached to roles).

23. What is inference control?

A control that prevents a user from deducing sensitive information indirectly, by combining legitimate answers.

24. What is a covert channel?

A pathway by which information flows implicitly in a way that violates the privacy policy of the organization.

25. What is the main issue with encryption?

Key management — the key must be available at startup but must not be stored with the data, and losing it makes the data unreadable.

26. What is a threat?

Any intentional or accidental event that may adversely affect the system.

PL/SQL control structures

27. Name the three categories of control structure.

Conditional, iterative and sequential.

28. Difference between EXIT and EXIT WHEN?

EXIT leaves the loop unconditionally; EXIT WHEN evaluates a condition first and leaves only if it is true.

29. Can a WHILE loop body execute zero times?

Yes. The condition is tested at the top, so if it is false or null on entry the loop is bypassed.

30. Can a FOR loop body execute zero times?

Not for a normal ascending range — but if the range is empty (lower bound greater than higher bound without REVERSE) the body does not execute.

31. What happens if the FOR loop bounds are equal?

The body executes exactly once.

32. What does EXIT outer do in nested loops?

It exits every enclosing loop up to and including the labelled loop named outer.

33. What does the NULL statement do?

Nothing — it is a no-op, used to make it clear that a branch is deliberately empty.

34. Name two GOTO restrictions.

It cannot branch into an IF, CASE, LOOP or sub-block; and it cannot branch out of a subprogram. (Also: no jumping between IF clauses or CASE WHEN clauses; and from an exception handler it may jump out to an enclosing block but not back into the current block.)

Cursors and views

35. What is a cursor?

A pointer to the result set of a SQL query against database tables.

36. What is the active set?

The rows in the context area that meet the condition; its size equals the number of such rows.

37. Name the four explicit cursor steps.

Declare, open, fetch, close.

38. Why is SQL%ISOPEN always FALSE?

Because Oracle closes the implicit cursor automatically after executing the associated statement.

39. Why must EXIT WHEN come immediately after FETCH?

Because the cursor attribute reflects the most recent fetch; testing it immediately prevents the loop from processing a row that was not retrieved.

40. What is a view?

A specific representation of data from one or more tables, storing only the query and not the data.

41. What is a base table?

A table referred to in the definition of a view — the table that actually stores the data.

42. How many columns can a view have?

A maximum of 1000, as in tables.

43. Name the five conditions for updating a view.

No GROUP BY or ORDER BY; no DISTINCT; all NOT NULL values; not built from nested or complex queries; and built from a single table.

44. What does WITH CHECK OPTION do?

It makes the view's WHERE condition a constraint on writes: an INSERT or UPDATE that would not satisfy it returns an error.

45. Does dropping a view delete data?

No — it removes only the view definition, because the view stored no data of its own.

Common mistakes and examination traps

The ten most costly errors
  1. Writing “authentication controls what a user may access”. It is authorization that does that.
  2. Saying a table can have two primary keys. It can have many candidate keys, one primary key.
  3. Reversing the direction of a dependency and reading X → Y as “X depends on Y”.
  4. Splitting the left side of a dependency (from AB → C inferring A → C). Decomposition is right-side only.
  5. Treating 4NF as a replacement for BCNF. 4NF includes BCNF.
  6. Claiming a WHILE loop always runs at least once. Its condition is at the top.
  7. Writing ELSE IF instead of ELSIF.
  8. Testing %NOTFOUND before the first FETCH in a cursor loop.
  9. Forgetting that an unclosed cursor holds server memory.
  10. Believing denormalization means skipping normalization. It is applied after it.
